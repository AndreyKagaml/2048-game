# 2048 Game

A classic implementation of the **2048 puzzle game** built with HTML, SCSS and Vanilla JavaScript. The goal is to combine numbered tiles, reach the 2048 tile and achieve the highest possible score.

---

## Game Preview

The game is deployed via GitHub Pages and is publicly accessible here:

[**Play the Game\!**](https://andreykagaml.github.io/2048-game/)

---

## Technologies Used

- **HTML5:** Semantic markup for the game interface and board structure.
- **CSS3 (SCSS/SASS):** CSS preprocessor used for modular, maintainable stylesheets and visual effects.
- **JavaScript (ES6+):** Implements game logic, tile movement, merging algorithms, score calculation and user interactions.
- **Stylelint & ESLint:** Code quality tools used to maintain consistent styling and prevent common JavaScript errors.

---

## Features

- **Classic 2048 Gameplay:** Play on a 4x4 grid and combine tiles with matching numbers.
- **Keyboard Controls:** Move tiles using the arrow keys (Up, Down, Left, Right).
- **Core Game Logic:** Accurate implementation of tile merging, movement and randomized tile generation.
- **Score Tracking:** Automatically calculates and updates the score whenever tiles are merged.
- **Win Detection:** Displays a winning message when a tile reaches 2048.
- **Game Over Detection:** Detects when no more valid moves are available.
- **Start and Restart:** Start a new game or restart the current game at any time.

## Getting Started

Follow these instructions to run the project locally.

### 1\. Clone the repository

Open your terminal and execute:

```bash
git clone https://github.com/AndreyKagaml/2048-game.git
cd 2048-game
```

### 2\. Install dependencies

Install all required packages:

```bash
npm install
```

### 3\. Run the project locally

Install all required packages:

```bash
npm install
# or
yarn install
```

### 4\. Run the project locally

Start the local development server:

```bash
npm start
# or
yarn start
```
